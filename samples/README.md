# Sample documents

Open any of these in Markooj to try it out. They are also the documents the store and README pictures are made from
(`npm run images`). All text, figures and data here were written for Markooj and may be reused freely.

| File | What it shows |
|:-----|:--------------|
| `sediment-transport/sediment-transport.md` | A short research paper: chapter numbering, numbered equations, a figure and a table with captions, cross-references, citations from `references.bib`, a note callout, a Mermaid diagram and a footnote |
| `canal-survey-notes.md` | Field notes in English and Urdu, with short Arabic and Persian paragraphs and a bilingual table |
| `thesis-chapter-3-outline.md` | A thesis chapter outline with a word target, task lists, a comment, a hidden note and a tip callout |
| `lab-notebook.md` | A lab notebook with a measurement table, inline math and a Python block you can run with Ctrl+Alt+Enter |
| `macros/fall-velocity-summary.py` | A Python macro for the lab notebook: paste it into Developer → Editor and press Run |
| `draft-abstract.md` | A rough draft with common mistakes, for trying the Writing Assistant (Review → Writing Assistant) |

The chart in `sediment-transport/figures/` is an SVG drawn for this sample; the data are made up for illustration.
