# Getting started

Six short steps, from a blank page to a finished PDF. If you have used Word, most of this will feel familiar.

## Welcome and what's new

The first time you start Markooj, the **Welcome** screen shows what it can do. Each feature has a **Show me** button that starts a short guided tour on the real buttons, in a practice document, so your files are never touched. **Take the 2-minute tour** walks through the ribbon, the four modes and saving, **Open a sample document** opens a short research paper to try things on, and **Start writing** takes you to your page. Press **Esc** to close it; **Tab** and the arrow keys move between the buttons.

After each update, Markooj shows **What's new** once, with the main changes of that version. **See all changes** opens the full list.

Open either one any time: **Help → Welcome** or **Help → What's New**, or press **Alt+Q** and type `welcome`. To see the Welcome each time Markooj starts, tick **Show this when Markooj starts**. If you started Markooj by opening a file, a small **Welcome** (or **What's new**) button waits in the status bar instead, so your document stays in front.

## 1. Start a document

Markooj opens with a blank page. To start from a ready-made layout instead, click **File**, then **New**, and pick one:

- **Research paper:** abstract, math and citations.
- **Lab notebook:** dated entries and checklists.
- **Thesis chapter:** sections, theorems and a diagram.
- **Meeting notes:** agenda, decisions and actions.
- **Literature review:** a table that compares studies.

To open a file you already have, press **Ctrl+O**, or drag it onto the window. Markooj opens Markdown, Word, PDF, DjVu, EPUB, LaTeX, HTML, text and more. Each document gets its own tab.

## 2. Type and format

Click on the page and type. The **Home** tab works like Word's:

- **Bold**, *italic* and underline: **Ctrl+B**, **Ctrl+I**, **Ctrl+U**.
- A heading: click **Heading 1** or **Heading 2** in the Styles gallery, or press **Ctrl+Alt+1** and **Ctrl+Alt+2**.
- A list: **Bullets** (Ctrl+Shift+L) or **Numbering** (Ctrl+Shift+7). Tab and Shift+Tab move a list item in and out.

Behind the page, Markooj writes Markdown: `**bold**`, `# Heading`, `- item`. You never have to type it. To see the Markdown for any part of the page, select it and press **Ctrl+Shift+/** (What's this in Markdown?).

## 3. Add an equation, a table and a picture

- **Equation:** press **Alt+=**. Type in the visual editor, or in LaTeX on the right. Both stay in step. Click **Insert**.
- **Table:** on the **Insert** tab, click **Table** and point to choose the number of columns and rows. Click into any cell and type. Tab moves to the next cell.
- **Picture:** on the **Insert** tab, click **Picture**, or drag a picture onto the page. Markooj copies it into an `assets` folder next to your document.

## 4. Save

Press **Ctrl+S**. The first time, Markooj asks where to save. Your document is saved as a Markdown (`.md`) file: plain text that opens anywhere, works with Git and never locks you in.

If you close a document without saving, its text is kept for at least 7 days. See [Recover unsaved work](recover.md).

## 5. Check your writing

Words the dictionary does not know get a red line as you type. Right-click one for suggestions. For grammar, clarity and style, open **Review → Writing Assistant**. Every suggestion says what is wrong, offers a fix and has a **Why?** button that explains the rule. Markooj never changes your text by itself. See [Writing Assistant](writing-assistant.md).

## 6. Share it

Click **File**, then **Save As / Export**, and pick a format: **PDF**, **Word document**, **EPUB e-book**, **Web page**, LaTeX and more. Your Markdown file stays as it is; the export is a separate file. To print, press **Ctrl+P**.

## Where next

- Try the four editing modes: **Ctrl+1** Word, **Ctrl+2** Inline, **Ctrl+3** Simple (Markdown and a live preview), **Ctrl+4** Read. See [The window](the-window.md).
- Number your equations and figures and refer to them: [Numbering and cross-references](numbering-and-cross-references.md).
- Cite your sources from a BibTeX library: [Citations and references](citations-and-references.md).
- Find any command by typing a few letters: press **Alt+Q**.
